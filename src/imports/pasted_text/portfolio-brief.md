# DESIGN AN AWARD-WINNING PORTFOLIO — ASAD UR REHMAN

Create a completely original, visually exceptional personal portfolio website for:

**ASAD UR REHMAN**

He is a Creative Developer, Full-Stack Engineer, UI/UX Developer and Digital Product Builder.

IMPORTANT:
This website must feel dramatically different from typical dark creative developer portfolios.

Do NOT create:

* an all-black website
* a dark brutalist portfolio
* a clone of any reference website
* a generic developer template
* excessive glassmorphism
* excessive gradients
* ordinary card-based layouts

Instead, create a **bright, elegant, energetic and highly artistic digital portfolio** that feels like a combination of:

EDITORIAL MAGAZINE
+
DIGITAL ART
+
PREMIUM PRODUCT DESIGN
+
CREATIVE TECHNOLOGY
+
MODERN PERSONAL BRAND

The website should feel like a designer and engineer built it together.

The visual identity should be so strong that someone immediately remembers:

**ASAD UR REHMAN**
